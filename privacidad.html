Política de Privacidad — Dinero Claro Recomienda

Última actualización: 20 de septiembre de 2026

1. Qué datos recogemos

Únicamente el token de OAuth de TikTok necesario para subir videos a la bandeja de borradores del creador (permiso video.upload). No recogemos nombres, correos, ni ninguna otra información personal.

2. Cómo usamos los datos

El token se usa exclusivamente para subir los videos de recomendaciones de productos a los borradores de TikTok mediante la Content Posting API oficial. La publicación directa está desactivada: el creador publica manualmente cada video.

3. Con quién compartimos los datos

Con nadie. Los datos no se venden, no se alquilan y no se comparten con terceros.

4. Conservación y eliminación

El token se conserva solo mientras la aplicación esté vinculada. El creador puede desvincularla en cualquier momento desde los ajustes de TikTok, lo que invalida el token de inmediato.
