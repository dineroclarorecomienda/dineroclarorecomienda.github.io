Términos de Servicio — Dinero Claro Recomienda

Última actualización: 20 de septiembre de 2026

1. Qué es esta aplicación

"Dinero Claro Recomienda" es una aplicación que conecta la cuenta de TikTok del creador para subir automáticamente sus videos de recomendaciones de productos a la bandeja de borradores de TikTok. La aplicación usa el Login Kit y la Content Posting API oficiales de TikTok.

2. Cómo funciona

  • Vinculación única: el creador vincula su cuenta de TikTok una sola vez a través de la pantalla oficial de autorización de TikTok (permiso: video.upload).
  • Solo borradores: la aplicación sube cada video como FILE_UPLOAD a los borradores del creador. La publicación directa está desactivada.
  • Publicación manual: nada se publica en TikTok sin que el creador abra la aplicación de TikTok, revise cada borrador y lo publique manualmente.

3. Datos

La aplicación guarda únicamente el token de OAuth necesario para subir los videos a los borradores. No se recoge, almacena ni comparte ninguna otra información personal.

4. Revocación

El creador puede desvincular la aplicación en cualquier momento desde los ajustes de TikTok (Ajustes → Seguridad → Aplicaciones autorizadas). Al hacerlo, el token deja de funcionar de inmediato.
